# English-learning-manager
英语学习管理 Agent Skill

## ✨ 功能简介
面向学生的英语学习辅助工具，一体化管理英语学习流程。
- 每日学习计划制定与打卡提醒
- 作业批改、语法纠错与讲解
- 每周学习复盘与计划调整
- 错题归档、定期复盘复习
- 生词收集、单词本汇总记忆

## 📁 文件说明
- `SKILL.md`：技能核心定义、提示词、调用规则
- `openai.yaml` / 配置文件：Agent 调用配置
- 脚本文件：执行逻辑、数据读写、复习算法

## 🎯 使用场景
适合搭载在自定义 Agent 中，作为独立子技能调用，专注英语学习闭环管理。
